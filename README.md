# Сервис прогнозирования инцидентов в инженерных коллекторах

Команда **«Дискреция творца»** — задача №8 «Город», ЛЦТ-2026.
Постановщик: Департамент ЖКХ Москвы. Эксплуатант: АО «Москоллектор».

---

## Идея

Сервис не выдаёт число. Он выдаёт **вердикт с обоснованием на языке диспетчера**:

> 🔴 **Объект Кси, ПК213 — отказ шлейфа, 87 % в ближайшие 24 ч**
>
> **Почему так решено:**
> 1. 74 из 75 дымовых датчиков отрезка молчат более 8 ч — вклад +38 %
> 2. Канал ДД ПК772 за 7 суток дал 240 переходов «Неисправен» при норме 3 — вклад +22 %
> 3. Отрезок непрерывен по пикетам: 57 точек из 59 — признак общего кабеля — вклад +15 %
>
> **Это НЕ пожар:** сработок дыма за сутки — 0.
> **Чего мы не видим:** тепловых датчиков на объекте нет, подтвердить температурой нечем.

Последняя строка — принципиальная. Тепловых датчиков нет на 13 объектах из 16,
датчиков затопления — на 8 из 16. Сервис, который в этих зонах скажет «риск низкий»,
обманет диспетчера. Он обязан сказать «здесь я слеп».

## Троичная логика

Состояние канала имеет три значения, а не два: **+1** отклонение, **0** неизвестно, **−1** норма.

Правило «логических доменов» заказчика записывается одной операцией — `min(t₁, t₂)`:

- `min(+1, −1) = −1` — сосед в норме, одиночную тревогу не засчитываем
- `min(+1, 0) = 0` — соседа нет → **«не знаю», а не «нет»**
