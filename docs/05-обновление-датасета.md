## 6. Что меняется в плане разработки

1. **Локация переходит на официальную иерархию.** Единица — `ид_объект` (L3, 78 значений),
   с разворотом до L2 и детализацией пикетом. Суррогат `(база, ПК)` больше не нужен как основа,
   остаётся как уточнение внутри объекта.
2. **Требование ТЗ «определение локации оборудования» выполнимо** для 96,99 % событий.
3. **«Интерактивная карта»** становится деревом объектов (район → 16 объектов → 78 подобъектов)
   плюс линейная схема по пикетам. Географических координат по-прежнему нет.
4. **Агрегация модели** — на уровне L3, потому что L2 склеивает разные коллекторы
   (объект Зита содержит 12 подобъектов от 5 баз).
5. **Карта наблюдаемости** становится отдельной ценностью продукта и показывается в интерфейсе.
6. **Флаг `SHOW_TOPONYMS`** предлагается включить по умолчанию — ограничение отпало.
